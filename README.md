# eodh-community-notebook-competition

## Overview 
Welcome to the EO Data Hub (EODH) Community Notebook Competition where we invite participants to create reproducible and educational notebooks using the Hub's Notebook service and a selection of EODH provided datasets (see the [Catalogue](https://eodatahub.org.uk/static-apps/sg-rc-ui/prod/index.html#/) for details).

## Rules

* Participants must use one or more datasets from the EODH catalogue (Notebooks where multiple datasets are integrated score extra). 
* Participants may combine external datasets if required.  
* Notebooks **MUST** be reproducible and able to be shared publicly, including self-installation of any package dependencies. This means that **open** datasets must be used so that the notebooks can be run by anyone without needing to purchase data or sign up to any licence.
* The notebook must conduct some Earth Observation analysis. 
* The code can be completed using either Python or R. No other code language will be accepted.
* Machine Learning applications are welcomed, please contact the EODH team with your processing requirements. 
* Notebooks must be compatible with, and testable on, the EODH Jupyter Notebook environment. We encourage notebook submissions to be developed and hosted within the EODH Jupyter environment. 
* Please name all authors or contributors to the notebook so that they can be appropriately acknowledged.
* The template notebook should be followed for all submissions.
* An individual and/or organisation can submit more than one Notebook.

## Eligibility 

The notebook can be an individual or collaborative submission and can be submitted on behalf of an organisation, but this is not a requirement.  Everyone is invited to submit, including students, researchers, research groups and institutes, startups, developers and EO professionals. EODH see this competition as an ideal opportunity for early career employees, students and graduates and we encourage submissions from across the academic, industry and public sectors. 

## Assessment criteria

| Category | Points available | High-scoring description | Scoring areas |
|---|---:|---|---|
| **Reproducibility** | 40 points | Robust, openly reproducible and shareable EO workflow that runs end to end on the EODH Jupyter notebooks environment, can be independently reproduced by the EODH assessment team, demonstrates a useful off-the-shelf application and has clear potential to scale. | Execution, Reproducibility, Workflow, Shareability, Scalability, Documentation |
| **Content (Visualisation OR Outputs)** | 30 points | Engaging notebook-generated visualisation that tells a clear story or brings data to life, OR well-presented, decision-ready outputs are produced by the analysis. | Notebook-generated result, Communication, Presentation quality, Engagement OR Decision-readiness |
| **Innovation (Use of data)** | 30 points | Multiple EODH datasets are synergised effectively in a scientifically sound analysis that benefits from their combination OR demonstrates an innovative or novel EO use case. | Scientific soundness, Attribution, Data synergy OR Innovation |

## Submission instructions 

We will be using git and GitHub. If you are not familiar with these technologies then this competition provides a great opportunity to learn about them. The following guides explain some of the common tasks:

* [Forking a repository](https://docs.github.com/en/pull-requests/collaborating-with-pull-requests/working-with-forks/fork-a-repo)
* [Cloning, branches and creating a commit](https://docs.github.com/en/get-started/using-git/about-git#example-contribute-to-an-existing-repository) 
* [Pull requests](https://docs.github.com/en/pull-requests/collaborating-with-pull-requests/proposing-changes-to-your-work-with-pull-requests/creating-a-pull-request#creating-the-pull-request) 


### Submission process

* Click **Use this template** in this repository and create your own independent repository.  
* This independent repository can then be cloned into an EODH Jupyter environment or wherever you will work. 
* Complete your notebook work in that repository. 
* Make the repository public. 

### Submission form 

Email enquiries@eodatahub.org.uk with a link to your submission repository (which should contain an obvious Notebook). In the email, also list all authors, the title and description of the notebook and the notebook filename.

### Post-submission

The EODH may decide to add a selection of the submitted notebooks into this repository so that there is a central location where new EODH users can browse the possibilities of the platform. EODH may also make selected notebooks available through the wider EODH platform.
